## Runtime

| Requirement | Version                                                              |
| ----------- | -------------------------------------------------------------------- |
| Node        | 20.19 or later                                                       |
| Svelte      | 5.x. Svelte 4 and the legacy component API are not supported.        |
| Browsers    | any with support for declarative shadow DOM, for server-rendered use |

## Packages

| Package                        | Status       | Peer dependencies                                                                |
| ------------------------------ | ------------ | -------------------------------------------------------------------------------- |
| `@svebcomponents/build`        | Beta         | `tsdown >=0.15`                                                                  |
| `@svebcomponents/auto-options` | Beta         | `svelte ^5`                                                                      |
| `@svebcomponents/ssr`          | Beta         | `svelte ^5`, `vite ^6 \|\| ^7 \|\| ^8`, `tsdown >=0.15`, `rolldown >=1.0.0-beta` |
| `@svebcomponents/ssr-vue`      | Experimental | `vue ^3.5`, `vite ^6 \|\| ^7 \|\| ^8`                                            |
| `@svebcomponents/ssr-react`    | Experimental | `react ^19`                                                                      |
| `@svebcomponents/ssr-astro`    | Experimental | `astro ^5`                                                                       |
| `@svebcomponents/utils`        | Beta         | none (an internal dependency of the packages above)                              |

**Beta** means ready for real-world evaluation and early production adoption,
with APIs that may still change before 1.0. **Experimental** means the API is
expected to change.

## Host framework notes

- **SvelteKit / Vite + Svelte** — the reference integration. Asynchronous
  components additionally need
  `compilerOptions.experimental.async` in the host app.
- **Vue 3.5+** — requires Vite. No synchronous/asynchronous split.
- **React 19+** — no bundler requirement; works anywhere React does. React 18
  and earlier stringify props passed to custom elements and do not attach
  listeners for custom event names. Asynchronous components need the
  [RSC entry point](/core-concepts/ssr/framework-integrations/#synchronous-by-default-with-an-rsc-opt-in).
- **Astro 5+** — no client-side counterpart; the element hydrates itself.

Every non-Svelte host must also opt into Svelte's async SSR mode explicitly
before rendering an asynchronous component; see
[async rendering outside Svelte](/core-concepts/ssr/#async-rendering-outside-svelte).

## Server rendering requires Svelte

`@svebcomponents/ssr` calls Svelte's server renderer, so `svelte` must be
installed as a server-side dependency of the host application even when it
contains no Svelte components of its own. A component package's server bundle
ships its own Svelte runtime, but the renderer entry point does not.
