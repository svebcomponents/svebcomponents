title: Compatibility

Each svebcomponents package remains in beta. Its API may change before 1.0.

## Runtime requirements

| Runtime                | Requirement                      |
| ---------------------- | -------------------------------- |
| Node                   | 20.19 or newer                   |
| Svelte                 | 5.x with the runes component API |
| Browser builds         | custom elements and shadow DOM   |
| Server-rendered output | declarative shadow DOM           |

svebcomponents does not support Svelte 4 or the legacy component API.

## Package peers

| Package                        | Peer dependencies                                                                             |
| ------------------------------ | --------------------------------------------------------------------------------------------- |
| `@svebcomponents/build`        | none                                                                                          |
| `@svebcomponents/auto-options` | `svelte ^5`                                                                                   |
| `@svebcomponents/ssr`          | `svelte ^5`; optional `vite ^6 \|\| ^7 \|\| ^8`, `tsdown >=0.22`, and `rolldown >=1.0.0-beta` |
| `@svebcomponents/ssr-vue`      | `vue ^3.5`; optional `vite ^6 \|\| ^7 \|\| ^8`                                                |
| `@svebcomponents/ssr-react`    | `react ^19`                                                                                   |
| `@svebcomponents/ssr-astro`    | `astro ^5`                                                                                    |

`@svebcomponents/utils` has no peer dependencies. The public packages install
it as a dependency.

## Host support

- [SvelteKit](/server-rendering/sveltekit/) uses the Vite plugin and wrapper
  components from `@svebcomponents/ssr`.
- [React 19](/server-rendering/react/) uses a JSX runtime or an explicit
  `CustomElement` component. React 18 cannot pass custom-element properties and
  events with the React 19 behavior.
- [Next.js](/server-rendering/nextjs/) App Router uses the React adapter.
- [Vue 3.5](/server-rendering/vue/) and [Astro 5](/server-rendering/astro/) use
  host-specific Vite plugins and wrappers.

## Async server rendering

A component that awaits during Svelte's server render needs
`compilerOptions.experimental.async` in the component package and, for
SvelteKit, in the app. An async server-preparation hook needs an await-capable
host but does not need Svelte's async compiler mode.

Read [Async components](/server-rendering/async/) for each host path.

## Svelte in non-Svelte hosts

Install `svelte` in a React, Vue, or Astro app that server-renders these
elements. `@svebcomponents/ssr` calls Svelte's server renderer, even when the
host app contains no Svelte source.
