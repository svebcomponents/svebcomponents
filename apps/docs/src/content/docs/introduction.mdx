[Svelte has a compiler mode for custom elements](https://svelte.dev/docs/svelte/custom-elements).
Building a library with it takes more work: you have to supply attribute
metadata, configure several build targets, generate consumer types, and handle
server rendering.

svebcomponents is a toolkit for boilerplate-free, type-safe, server-renderable
web components with Svelte. It adds:

- `customElement.props` metadata inferred from your `$props()` types
- browser and server builds derived from package exports
- TypeScript declarations and a custom elements manifest
- declarative shadow DOM with hydration in Svelte, React, Vue, and Astro

You keep writing Svelte components. svebcomponents handles the library around
them.

## Author in Svelte

Declare the tag and write the component in Svelte:

```svelte
<svelte:options customElement="favorite-number" />

<script lang="ts">
  let { value = 0 }: { value?: number } = $props();

  function change(value: number) {
    $host().dispatchEvent(new CustomEvent("change", { detail: value }));
  }
</script>

<button onclick={() => change(value + 1)}>{value}</button>
```

The build enables Svelte's custom-element compiler mode. It reads `value` from
the TypeScript declaration and generates the metadata for number conversion,
attribute reflection, element types, and the manifest.

## Browser and server output

The browser build registers a standard custom element. Consumers can use it in
HTML or any framework without installing Svelte.

Add an SSR export and the build generates a server renderer. Host integrations
emit declarative shadow DOM and hydrate its existing nodes when the element
upgrades.

### TL;DR

Svelte's compiler can wrap a component in an `HTMLElement` subclass. That
wrapper mounts the component inside a shadow root and connects element
properties and attributes to component props.

The generated browser wrapper mounts from scratch during upgrade, replacing a
declarative shadow root. svebcomponents adds the server renderer and hydration
layer that preserve those nodes.
