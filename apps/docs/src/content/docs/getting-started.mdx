---
title: Getting Started
description: Create and run a svebcomponents project.
---

You need Node 20.19 or later. Start from the
[project template](https://github.com/svebcomponents/template):

```bash
pnpm dlx degit svebcomponents/template my-project
cd my-project
pnpm install
pnpm dev
```

The dev server runs a SvelteKit app that imports the component package.

## Write a component

In the component package, open `src/FavoriteNumber.svelte`:

```svelte
<svelte:options customElement="favorite-number" />

<script lang="ts">
  let { increments = 1 }: { increments?: number } = $props();
  let count = $state(0);
</script>

<button onclick={() => (count += increments)}>
  add {increments} to {count}
</button>
```

This is a [Svelte custom element](https://svelte.dev/docs/svelte/custom-elements).
The build reads the `$props()` type and supplies Svelte's attribute metadata,
so `increments="5"` reaches the component as a number.

## Build it

Run the package's build script:

```bash
pnpm build
```

The build writes the browser bundle and its types to `dist/client`. It also
writes `custom-elements.json` for editors and other custom-element tooling.

## Use it

Import the package once, then write the tag:

```svelte
<script lang="ts">
  import "my-components";
</script>

<favorite-number increments={5}></favorite-number>
```

Continue with [Authoring components](/authoring/). Read
[Publishing your package](/publishing/) when you need to add entries or change
the generated output.
